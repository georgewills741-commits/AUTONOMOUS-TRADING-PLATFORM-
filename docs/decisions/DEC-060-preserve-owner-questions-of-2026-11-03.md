## Decision

1. **The messages are preserved word for word**, as [owner decisions 27](../handoffs/owner-decisions-27-questions-on-quality-position-and-the-directive.md), a HISTORICAL source listed in the preserved-text manifest, each under its own dated heading. They were taken by script from their user turns of 08:07 and 08:16 UTC in the session record and kept byte for byte, including the spaces that end each of their lines, so `git diff --check` reports those four lines in this change; the texts are not trimmed to satisfy it. Each dated heading is the turn's time, which the round trip of the [documentation tools](../../tools/docs/README.md)' README takes; the banner gives the times they were sent too.
2. **They change nothing.** The first asks a question, which the builder answered from the repository, and asks the builder to continue while answering, which the existing order of work already provides ([DEC-048](DEC-048-preserve-and-apply-rule-0.md), decision 5); the second asks whether a directive was applied, which it is, through DEC-057. The work goes on in the order of the project state's "Next approved step".
3. **They are preserved with the change in progress when they arrived**, item 5, whose record names them ([traceability README](../traceability/README.md), Scope; DEC-048, decision 3), as owner decisions 25 was ([DEC-056](DEC-056-preserve-owner-question-of-2026-10-29.md), decision 3).

## Alternatives considered

- **Treat them as procedural.** Not chosen: each asks a question, which DEC-047 (decision 7) keeps, as [owner decisions 25](../handoffs/owner-decisions-25-question-on-the-stage-and-progress.md), a question of the same kind, was kept (DEC-056).
- **Date them by their queue entries, 07:58 and 08:11 UTC.** Not chosen: the round trip of the documentation tools' README takes the recorded message, a typed turn or a message the client delivered while the builder worked, and a queue entry is neither; the banner gives both times.
- **Leave them to the next change.** Not chosen: they arrived while item 5 was in progress, before the copy its last Gate 3 run reviews was made, and the record names each such message with where it is preserved (traceability README, Scope); owner decisions 25 was preserved in the same way, with the change in progress when it arrived (DEC-056, decision 3).
- **One preserved text for each question.** Not chosen: two questions of one morning, sent during one change, are kept together, as [owner decisions 19](../handoffs/owner-decisions-19-questions-on-the-project-and-the-knowledge-base.md) keeps two.
- **Trim the spaces that end their lines, so that `git diff --check` stays clean.** Not chosen: a text kept in a text block equals the message as received, byte for byte (the documentation tools' rule for preserved texts).
