# Drafts

> **Status:** DRAFT material — NOT APPROVED, NOT AUTHORITATIVE, NOT VERIFIED, NOT PRODUCTION-READY. This directory keeps important unverified work so that it is not lost, without promoting it ([owner decisions 15](../handoffs/owner-decisions-15-stage-transition-persistence-and-commit-integrity.md), §1: "Committing a draft does NOT promote it to approval"; [DEC-047](../decisions/DEC-047-preserve-stage-transition-persistence-rules.md), decision 3), isolated and labelled as the [master execution constitution](../builder/master-execution-constitution.md) asks of drafts (§10: "Drafts may exist only when explicitly isolated and clearly labelled"). This index is the canonical record of each draft's disposition. A draft here is never a source: no canonical record cites it as one, and each draft's text is kept in text blocks, so its decision numbers and its requirement, rule, and value IDs define nothing. A draft leaves this directory's list only when the step it serves replaces it: that step compares it with the canonical records, merges what remains valid under the rules then in force, keeps its provenance, and marks it superseded by the record that replaces it (owner decisions 15, §7, §8).
